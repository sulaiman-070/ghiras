# 🌿 غِراس — GHIRAS
> **تطبيق إسلامي لبناء عادات روحية هادئة ومستمرة مع القرآن الكريم والأذكار**
> *"أحبُّ الأعمالِ إلى اللهِ أدْومُها وإنْ قلَّ"*

---

## ✨ المميزات الرئيسية
* **📖 المصحف الشريف كاملاً (604 صفحات • 114 سورة • 6236 آية):**
  - رسم وضبط المصحف العثماني المعتمد دولياً (مجمع الملك فهد).
  - إطار مذهب كلاسيكي أصيل يحاكي ملمس وصفحات مصحف المدينة المنورة.
  - تصفح الصفحات صفحة بصفحة (1..604) مع أزرار التقليب وانتقال مباشر لأي صفحة.
  - تلاوة صوتية عطرة لجميع آيات القرآن بصوت الشيخ **مشاري راشد العفاسي**.
  - فهرس شامل لـ 114 سورة مع بحث لحظي باسم السورة أو رقمها.
  - التحكم بحجم الخط القرآني ووضع الخشوع (ملء الشاشة).
* **🌱 حديقة الطاعات ونظام الإنجاز (The Garden):**
  - نبتة تفاعلية حية تنمو مع التزامك اليومي من بذرة صغيرة إلى شجرة باسقة.
  - تعزيز إيجابي بدون عقاب أو تصفير قاسي للسلسلة (مبدأ الرفق والتدرج).
  - نقاط خبرة (XP) وأوسمة إنجاز قابلة للفتح والمشاركة.
* **🤲 الأذكار اليومية:**
  - مسبحة تفاعلية لأذكار الصباح والمساء مع عدادات ذكية واهتزاز تفاعلي.
* **👥 الصحبة الصالحة:**
  - مجموعات تشجيعية وتنافس إيجابي في الطاعات بضغطة زر.
* **📱 Mobile-First & Offline-First:**
  - تصميم مخصص للهواتف الذكية ومتوافق مع جميع الشاشات.
  - يعمل أوفلاين دون الحاجة لاتصال بالإنترنت لتصفح المصحف.

## 🚀 تشغيل التطبيق محلياً
لا يتطلب أي بناء معقد، يعمل بـ Node.js فوراً:

```bash
# 1. تشغيل السيرفر المحلي
npm start
# أو
node server.js
```

افتح المتصفح على:
`http://localhost:5500`

## 🛠️ التقنيات المستخدمة
* **Frontend:** Vanilla JavaScript (ES Modules), HTML5 Semantic.
* **Styling:** Pure CSS Design Tokens, RTL-First, Classical Arabic Typography (`Amiri Quran`, `Amiri`).
* **Data Engine:** Tanzil verified Uthmanic Quran Dataset (Full offline 604 pages).
* **Audio:** High Quality 128kbps recitation CDN per verse.
